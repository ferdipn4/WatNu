# Logos

- `watnu-mark.svg` — the app icon: a 128px `radius-xl`-proportioned tile in accent `#d01f29` with the white (`#ffffff`) five-pointed star. Use at 24px and up; never on a red ground.
- `watnu-star.svg` — the star alone, single ink `#d01f29` (the light accent); on dark surfaces recolour to `#ff6b66` by editing the fill, since `<img>` cannot inherit colour. Sits before the name in the header wordmark at 16px.
- `watnu-wordmark.svg` — "WatNu" set in Bricolage Grotesque 800, outlined, single ink `#d01f29`; 298×70 at 100px cap height. Use where the display font cannot load (email, social cards); in the app the header sets the name as live text.
- Clear space around any of them: the star's width. Minimum sizes: mark 24px, wordmark 80px wide.
